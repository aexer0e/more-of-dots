# More of Dots 1.3.2

- Exported videos now include the game's music and sound effects, with separate volume controls in the export dialog.
- New faster export speeds of 15x, 20x, and 30x, with 10x selected by default.
- Leaderboards show when each player was last active, and the table can be sorted by it.
- Your own row can be hidden from the comparison chart.
- Corrected the tick labels under the export sliders, which did not line up with the values they marked.
- Requires recorder 1.3.2. The export dialog installs it for you.
