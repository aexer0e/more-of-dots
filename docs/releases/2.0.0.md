# More of Dots 2.0.0

- Replays now play directly in the app, with seeking, zoom, speed controls and stat toggles.
- Replays can be recorded with no separate recorder installation needed, at up to 60x faster speeds.
- Added support for the new game modes.
- Added filtering by maps.
- Replay caches no longer stop at a 500 MB limit; only the most recently opened simulation is kept on disk.
- Various QoL features and bug fixes.
