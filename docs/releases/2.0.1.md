# More of Dots 2.0.1

- Corrected historical replay simulation, including production, retreat, movement precision and ship damage. Verified 741 complete replays against their original game builds with exact simulation-state matches.
- Expanded bundled terrain and starting-unit layouts for historical, Experiment and multiplayer replays.
- Fixed the map editor's snow colour to match the game.
- Fixed projection and order-line thickness when resizing or zooming the replay player.

One recording in the validation collection crashes its original game builds on an order for a nonexistent unit. Its complete playback remains unverified.
