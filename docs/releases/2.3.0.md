# More of Dots 2.3.0

- Replay cards now show how a match went. Each side's troop count is drawn as a line across the card, so you can see the shape of a game before playing it. Lines for a large library are worked out in the background the first time and are stored afterwards.
- The replay engine is rewritten in Rust and no longer needs .NET. Replays open and prepare about four to five times faster, and playback is unchanged: all 2,557 replays compared with the previous engine gave identical results.
