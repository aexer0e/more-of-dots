# More of Dots 2.5.0

- The map editor is rebuilt. Maps keep only the fields the game reads, shock units are no longer placed by hand, and a Shock units view shows which infantry the game turns into shock units in experiment matches. Placing infantry does not change which units already placed become shock units.
- New terrain tools: line, curve, and rectangle, ellipse and polygon shapes, filled or outlined. Every terrain tool shows the exact pixels it will paint before you click. A smoothing brush and Smooth whole map straighten jagged edges and remove specks while keeping the game's colours.
- Symmetry mirrors edits left and right, top and bottom, by a half turn, or four ways, with copies going to the next teams.
- Front lines, units and cities are drawn as in the replay player, and each team shows its funds per payment.
- Run plays the map from its first frame with the game's controls. Units of every team take orders.
- A 2v2 control view shows which player commands each unit.
- New maps can be 960 x 540 or 1920 x 1080, and are named after the map. Click a map's name in the library or the editor to rename it.
- Import from .rep makes a map from a replay's map, with a card for each map in your replays.
- Leaving the editor, switching tabs or closing the app with unsaved changes asks whether to save them as a draft or discard them.
- In the replay player's live matches, short arrows drawn from a unit now give an order.
