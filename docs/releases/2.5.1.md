# More of Dots 2.5.1

- The map editor saves maps straight to the game. Drafts are gone: a new map is saved the first time each team has units, and a map that the game could not load is never saved. Drafts from earlier versions are moved into the game when they can be loaded.
- Import adds maps from a 4 digit map code, from your replays, or from .rep and map .txt files, and shows which maps are already in your library. New map is the first tab of the same dialog.
- The map library is redesigned: one header with search, a team filter and sort, a menu on each map with Rename, Duplicate and Delete, and a selection bar for deleting several maps at once.
- Deleting maps can be undone for 5 seconds.
- Import on the Replays page has a new icon and name.
- In live matches on the site, players who open a room after the start can watch or ask to join a side, and holding the right button pans the battlefield.
